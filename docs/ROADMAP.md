# NSCB Roadmap

## v2

- Dedicated NSCB Flutter application over the supported Rust embedding facade.
- Save restoration to a connected Switch as a separate typed, qualified device operation.
- Destructive device-administration capabilities, including uninstall/delete/cleanup operations, only as explicit typed and qualified operations rather than generic responder passthrough.
- Evaluate qualified network device transports such as responder FTP/HTTP workflows; v1 remains local-USB-only for device communication.
