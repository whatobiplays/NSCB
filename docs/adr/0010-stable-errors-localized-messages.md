# Separate stable error semantics from host-owned localized presentation

NSCB exposes stable typed error categories/codes and structured context across its CLI, Flutter bridge, and Rust embedding facade, while human-facing text is localized presentation owned by the active host. The CLI/TUI uses NSCB translation resources, the dedicated Flutter app uses its Flutter localization layer, and Argus maps NSCB semantics into Argus localization; no implementation string is displayed directly, and user-visible messages never expose code references, raw helper output, command lines, stack traces, or parser internals. Diagnostics may retain sanitized technical detail through the host-controlled diagnostics path.
