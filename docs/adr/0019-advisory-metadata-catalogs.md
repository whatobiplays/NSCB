# Treat external metadata as advisory enrichment

NSCB preserves read-only title metadata and update/DLC discovery behind NSCB-owned catalog contracts rather than binding application semantics to a legacy NUTDB/TitleDB schema or endpoint. Catalog snapshots are validated, cached with provenance, refreshable under the configured network policy, and allowed to become stale/offline without disabling local inspection, verification, transformation, or extraction. Metadata enrichment may improve presentation and report update/DLC availability, but it does not silently change transformation bytes, verification truth, patch decisions, or deterministic naming; database export uses normalized stable JSON, JSONL, and CSV schemas. v1 does not restore cloud-file providers or device autoupdate workflows. Catalog intro/description text may be machine-translated to English as a best-effort enrichment, but any translation failure must immediately fall back to the original-language text and can never fail a UI surface or Job.
