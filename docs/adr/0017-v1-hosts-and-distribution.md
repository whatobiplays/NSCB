# Ship CLI/TUI plus Argus support in v1

NSCB v1 ships the Rust core/embedding facade, CLI, interactive TUI, and supported Argus integration path; the dedicated NSCB Flutter application is a v2 deliverable. The NSCB release candidate must be qualified by an Argus-owned integration against the exact candidate/release while both projects retain independent release versions and schedules. v1 distribution is through one signed/checksummed portable GitHub Release archive per supported target rather than package-manager channels or crates.io, and each archive contains the `nscb` executable, shell completions, generated manual/reference, notices/licenses, release metadata, and redistribution-compatible native libraries needed by NSCB where practical. External system setup is reserved for genuinely system-owned prerequisites such as drivers, permissions, or udev rules.
