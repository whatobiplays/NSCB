# Ship CLI/TUI plus Argus support in v1

NSCB v1 ships the Rust core/embedding facade, CLI, interactive TUI, and supported Argus integration path; the dedicated NSCB Flutter application is a v2 deliverable. v1 distribution is through signed/checksummed GitHub Release artifacts rather than package-manager channels or crates.io, and shell completions plus generated command reference/man-page artifacts are produced from the canonical command model.
