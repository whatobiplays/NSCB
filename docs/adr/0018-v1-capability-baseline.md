# Make v1 a complete local-core and device-capable successor

NSCB 1.0 must ship the full retained local-core capability set: packaging/repacking, conversion, multi-content build/split, trimming, patching, inspection, verification, extraction, NSZ/XCZ compression/decompression, restoration, batch processing, rename/sanitize, metadata export, supported split representations, and NSX read/inspect/verify compatibility. The narrow device boundary is also a 1.0 requirement: qualified host-to-Switch install/transfer and Switch-to-host dump must work on every supported desktop target. Recursive discovery is explicit, split sets are treated as one logical content file, output naming and semantic ordering are deterministic, and mutating work never relies on filesystem enumeration order.
